# Digital Music Store Data Analysis

## Project Overview

This project analyzes music store data using SQL and MySQL Workbench to explore sales, customers, invoices, and music trends.

## Key Analysis

* Senior-most employee
* Countries with the most invoices
* Top invoice amounts
* Highest-revenue city
* Best customer
* Rock music listeners
* Top 10 Rock artists
* Tracks longer than average

## Tools Used

* MySQL
* MySQL Workbench
* SQL
